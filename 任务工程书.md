15. Stale Audio Gate
    ====================

Protocol v1 binary 没有 turn id。

所以只靠：
    generationId

不够。

必须：
    generationId
    +
    acceptDownlinkAudio
    +
    TTS lifecycle

Abort 后：
    acceptDownlinkAudio = false

所有 binary：
    drop

直到合法的新一轮：
    tts:start

才重新打开。
